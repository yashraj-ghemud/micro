Mosaic 2: Privacy Policy

Letvler · Effective 31 October 2026

Mosaic 2 is a Windows desktop IDE made by Letvler (developer: Yashraj Ghemud). It runs on your PC and coordinates the AI coding agent command-line tools you install, such as Claude Code, Codex CLI, Qoder CLI, Kiro CLI, Devin CLI, OpenCode, Antigravity CLI, Muse Code, GitHub Copilot CLI and Cursor CLI. This policy explains what information the app handles.

1. What Letvler collects

Nothing. Mosaic 2 has no Letvler account. It sends no analytics, telemetry, crash reports or usage data to Letvler, and Letvler runs no servers for the app.

2. What stays on your PC

Mosaic 2 stores these on your computer only, in its app data folder (%APPDATA%\Mosaic 2):

  • Your settings, theme, recent folders and window layout.
  • Agent, team and model settings, and your chat and mission history.
  • API keys you choose to enter for model providers.
  • Checkpoints: snapshots of your project files, taken before agents edit them, so you can restore them.
  • Computer Use settings: which apps you allowed, and a recent activity log.

To read your sign-in status, Mosaic 2 asks the installed agent CLIs. For Codex it reads only the plan type ("free" or "paid") from the Codex sign-in file on your PC, to pick the right model. Mosaic 2 never copies, stores or sends your sign-in tokens.

3. What is sent to third parties, and when

When you ask an agent to do something, Mosaic 2 passes your request to the agent CLI you selected. That CLI sends it to its own AI service under that company's terms and privacy policy. The request can include your prompt, relevant project files, and, for Computer Use or the built-in browser, screenshots and on-screen text of the windows or pages involved. Examples of these services are Anthropic, OpenAI, Google, AWS, Cognition, Qoder, Meta, GitHub, Cursor and OpenCode. If you enter an API key for a model provider, requests to that model go directly to that provider.

  • Computer Use captures a window only after you approve that app. Terminals, security tools, password managers and sign-in prompts are always blocked.
  • The built-in browser loads the websites you open. Its search box uses DuckDuckGo.
  • Installing agents: when you click Install, Mosaic 2 downloads that tool from its official source (for example npm or the vendor's website).
  • Remote access is off by default. If you turn it on, devices on your local network that have your access token can use Mosaic 2 on this PC. You can rotate the token or turn access off at any time.

Letvler does not sell, rent or share your information.

4. Your controls

  • Choose which agents and models to use, or use none.
  • Approve or deny every app before Computer Use controls it. Stop it at any time with Ctrl+Alt+Esc. Remove always-allowed apps in Settings › Computer Use.
  • Delete checkpoints, history and keys by deleting the app data folder, or by uninstalling Mosaic 2 and then deleting %APPDATA%\Mosaic 2.
  • To see or delete data held by an AI service, contact that service under its own privacy policy.

5. Security

Mosaic 2's local server listens only on this PC (127.0.0.1) unless you turn on Remote access, which requires an access token. Data stays under your Windows user account.

6. Children

Mosaic 2 is a developer tool. It is not directed at children under 13.

7. Changes

If a new feature changes how information is handled, we will update this page and its effective date.
